# 0.8.0 集中审查与限定复核

范围：当前工作区全部实现及未跟踪 Java，包括反应投递、三端 Mixin/配置、延迟队列、回显与合并、宽屏所有消费者、Toast/FAB、主题、HUD、固定 tab 与输入坐标。审查代理只读，主代理实施修正并复验；未以静态审查冒充游戏加载。

## 首轮发现及修正

| 级别 | 问题 | 修正 |
| --- | --- | --- |
| P1 | Fabric 原 screen 配置使用 Minecraft 的包名，新增 Reaction Mixin 实际在 com.atom.chat.mixin，启动时缺类 | 独立 reactions 配置，保留原 accessor 的 client 配置；新增配置引用实际 class 资源的回归，先红后绿 |
| P2 | 控制台 `/say` 经过原版 Disguised/Profileless 广播，各接收者曾获得不同编号 | canonical 广播 factory 返回委托包装器，每次广播共用一枚 UUID，实际发送时建立作用域 |
| P2 | 旧连接已排队 Receipt 可在 reset 后写入新会话 | Forge/Neo 在执行时比较来源 Connection；Fabric 比较稳定来源 addon 与当前 PacketSender |
| P2 | 异步发送可交错成 Receipt A、Receipt B、Chat B、Chat A | 在实际 Connection 调用处 Redirect，同一连接锁内顺序提交 Receipt 与原包，保留 callback/flush |

限定复核确认四项均已修正，无新增 P1/P2 或具体阻断。另核对最新 HUD：白色填充、三孔透明、原版 GUI scale、图标/文字缓存柔影及绘制状态恢复均正确；其他 UI 不重复扩审。

审查使用本地源码、`javap`、实际成品 JAR 和主流程测试日志；没有修改文件或自行运行构建。主代理重新核对成品内所有 Mixin 配置引用、三端修正测试、安装包与备份后才部署。
