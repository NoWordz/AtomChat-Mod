## 示例与边界

- `render_sketch.py` 是可编辑正本；每页 SVG 保留实际轮廓和文字的 title，修改文案后可再次导出。文本转路径只为跨机器查看时不丢字体。
- `assets/sample-emote.jpg` 是本机 CCB 测试实例中已有曼波表情的缩略示例。只读原文件，并复制缩略图至草图目录；没有把个人表情加入真实服务端资源包。
- 数字、名字、模板和“提取成功”都是静态演示，不是已经运行解析器。资源包 16 MiB 示意优先兼容现有客户端，真实限额及旧客户端策略仍需实施和验证。
- “提取成功”仅指样例字段；预览明确提示尚未获得 UUID。未解决缺身份/皮肤资料的首次陌生离线跨服场景。
- 主配置三个分类的“保存”提交同一份完整草稿。单条模板/常用语的“完成”只保留总草稿并回列表；返回/Esc 同样保留。常用语列表底部“返回资源包”仅导航，不提交网络。离开整个配置页才询问是否放弃。
- 普通保存/完成为强调色；移除为危险色，后续实现的破坏性确认必须继续复用现有红确认/灰取消。
- hover 静态洗色只是状态示意；入场、按压弹簧、水波、真实输入/IME/滚动与异步保存，均待同一代理继续实现及验证。
- 目前没有新增必须用户选择的视觉分歧。已有 grill 已确定族群、分类、输入材料和保存语义，本阶段是给用户看图，而非再发一组重复问题。

## 主代理审查与逐项处置

1. **常用语行为写错**：按 `QuickPhraseWiring.INSERT_SERVER` 的 composer 写入和 `QuickPhrasePanel.pickRow` 的 insert 路径核对，改为“点击后填入聊天输入栏”。没有修改实际常用语发送逻辑。
2. **packName 语义写错**：按 `AtomChatServerConfig.packName` / `PackBuilder.nameOverride` 核对，改为“服务器显示名”，说明“留空时使用服务器 MOTD”。示例值为“我们的服务器”，没有新增资源包命名字段。
3. **入口与完成流程缺失**：新增 `06-template-list` 展示列表入口和完整行操作。`04-template` / `05-phrase-edit` 底栏改为“完成”，说明返回列表保草稿；`03-phrases` 使用“返回资源包”。主配置页保留“保存”，不另造网络保存流程。
4. **chip 近似尺寸不合族群**：移除原 `40 / 18.75 / 9 / 178.66` 的 chip 常量，采用 `UiLayout` 和 `SettingsChipBar` 的真实公式、capHeight 基线及字号适配。原底栏外 17.5 / 内 10 留白保持不变。卡片继续合并分组并用内部线分隔。
5. **状态与紧凑主题覆盖不足**：补 `07-states` 的五种输入状态以及无匹配/歧义；补 `08-compact-light` 的360宽浅色节选。所有提取结果仍为静态演示，状态页明确标注未连接真实解析器；HTML 改为纯静态图片查看，移除伪交互样式。

审查修订只触及本 `sketch/` 目录。没有生产代码、实际协议、构建产物或测试实例变更。

本轮验证：重新生成 8 张单页 PNG、1 张总览及 8 份 SVG；PNG 解码检查和 SVG XML 解析通过。按 SVG 文案抽查了显示名/MOTD、常用语填入输入栏、两种编辑页只有“完成”而没有“保存”。打印核对了600/360面板的三格 chip 几何。已打开总览、资源页、两种编辑页、模板列表、状态页及窄浅色页，修正单条常用语说明末尾独字换行。以上均为草图验证，没有运行产品功能测试。
