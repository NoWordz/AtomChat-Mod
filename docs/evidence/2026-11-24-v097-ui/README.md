# AtomChat 0.9.7 界面验证

这里记录三档画质标志、设置文案和取色遮罩的阶段性验证。对照图由测试绘制。现场原图与原始测试日志留在本地。后续三端验证及最终行为见 [0.9.7 验证记录](../../verification/2026-11-24-v097-compatibility.md)。

## 画质标志与文案

- 极致使用 `assets/atomchat/quality/ultra.png`，512 × 512。延续原有红底、双重对话气泡和三点结构，外牌及两层气泡各有反光、倒角和阴影。
- 均衡直接复用 `assets/atomchat/mod_logo.png`。三端原图与 0.9.6 逐字节一致。
- 性能使用 `assets/atomchat/quality/performance.png`，24 × 24，源图仅有红白两色。画质卡使用最近邻采样。原生预览调用 `SkiaImages.drawRoundedImage`，在 65 和 96.24 物理像素宽时，图内均只出现两种源色。 [标志预览](quality-logo-preview.png)
- 本轮每端删去 3 条中文和 6 条英文设置文案的句末句号，两种语言各含 1 条服务器消息模板字段说明。保留句内断句、教程、确认、预览状态、报错和格式占位。同语种的三端资源逐字节一致。画质文案新增 7 个键，包括组名、三档名称和说明。
- 文案预览用实际语言资源和生产 `SkiaFontRenderer.wrapWords`，以 278 像素可用宽度抽查面板说明、禁用提示、服务器模板说明。 [文案预览](settings-copy-wrap.png)

## 遮罩证据

现场截图的像素测量将亮线定位在左侧实色描边内缘。1029 × 1599 样本的第 500 行，两侧外描边均为 `(22,24,29)`。左内缘 x=51 为 `(104,93,98)`，紧邻 x=52 为 `(45,41,46)`。右内缘 x=925 为 `(42,43,47)`，相邻 x=924 为 `(45,46,50)`。

生产外框把四条边分别吸附到设备像素。设置详情把未经同样吸附的几何送进取色和裁剪。旧遮罩内距保留小数，产生与外框分离的内侧抗锯齿覆盖。原生探针沿用 0.9.6 发布 JAR 的 `PanelBackground`、`PickerModalPaint`、`PictureRecorder` 绘制顺序，用同样的尺寸、默认 4 点描边和纯色背景复现几何问题。右缘旧值因背景不同与现场有差异。1.25 倍密度时，同类亮线移到右侧，旧版贴边布局还漏到外部一列。 [原生探针源码](../../../tools/probes/ModalBackdropEdgeProbe.java)

修正将遮罩与外框四条边对齐，覆盖描边内缘的混合像素。取色、确认、图片预览和裁剪窗共用此裁切。

## 检查结果与限制

- 探针在 Java 21 上独立编译和运行，使用 Fabric AtomChat 0.9.6、AtomLib 0.7.1、Skija 0.143.18。候选只替换 `PanelBackground` 和 `PickerModalPaint`。Skija raster 与隐藏 OpenGL 共跑 16 个场景，覆盖四档密度、浮动与贴边、两侧内缘、外部透明和圆角。0.9.6 有 6 项预期失败，候选全部通过。
- 语言和资产静态检查核对了 JSON、修改范围、翻译键及占位、均衡标志与 0.9.6 一致，以及性能标志最近邻放大的像素。
- 该阶段只验证独立绘制和静态资源。原壁纸下的取色和其他模态端到端行为未在该阶段验证。 [画质阶段验证](quality-progress.md)
