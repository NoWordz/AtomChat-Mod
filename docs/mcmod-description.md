原子聊天（AtomChat）把原版聊天屏改造成一个独立的「手机 App」风格聊天面板：圆角气泡、真实玩家名与圆形皮肤头像、表情 / 颜文字 / 表情包、图片与 GIF 动图消息、服务端媒体托管、复制与引用、多行输入，以及 QQ 式动效。

界面全部由 Skija 矢量绘制，不依赖原版聊天纹理。图片消息沿用 E33Chat 的 [[CICode]] 协议，可与 E33Chat / ChatImage 系模组互通；本项目是基于 E33Chat 理念的干净重写，不是它的 fork。

它是纯客户端模组：不装服务端也能用（图片走第三方图床）；服务端也装一份，才会解锁服务端媒体托管与自定义头像同步。

[h1=主要功能]

📱 手机面板 — 打开聊天时原版聊天 HUD 隐藏，改为独立面板：毛玻璃背景（可换壁纸）、底部三个标签页（聊天 / 个人 / 设置）、页面级推入弹出转场；

💬 消息气泡 — 自己在右、他人在左；真实玩家名 + 圆形皮肤头像（正版 / 离线皮肤自动降级）；引用胶囊、时间戳分隔、系统消息胶囊；

🖼️ 图片与 GIF 消息 — 原生渲染 CICode，按原图比例显示；GIF 在气泡内循环播放；透明底图直接透出面板背景；右键可保存原图；

📤 发送本地图片 — 点图片按钮选图、把图片拖进窗口，或复制后 Ctrl+V 粘贴；上传后自动插入草稿；

📦 服务端媒体托管 — 服务端装了 AtomChat 时，图片 / GIF 直接存到服务器再分发给其他玩家，不依赖第三方图床：内容寻址去重、按需分块下发、只走游戏连接、不开 HTTP 端口；服务端未装 / 关掉托管 / 超限 / 上传失败自动回退图床；

🎁 本服下发 — 进服时自动同步服务端的表情包、常用语，以及服务器图标与 MOTD；表情面板多出只读的「本服」分区，常用语面板多出只读的「本服」分组；逐文件 sha256 校验、只补差量；设置 → 隐私里可整体关掉接收；

😀 表情 / 颜文字 / 表情包 — 三个标签页带滑动指示器与推入动画；表情包存本地，默认不限数量（`atomchat-client.json` 的 `emoteMax` 可设上限）且格子可滚动（gif 在面板里只显示首帧，发出后正常播放）；

⚡ 常用语与输入 — 输入栏闪电按钮打开常用语（点选插入、不直接发送，最多 20 条、单条 ≤256 字）；多行输入、@ 提及、IMBlocker 命令态桥接、WATUT「对方正在输入」；

🔗 富文本与右键菜单 — 玩家名 / 正文支持颜色、下划线、点击与悬停：/tell、坐标、FTB 接受拒绝、外部链接均可点，裸 URL 自动转链接；右键菜单提供复制 / 引用 / 保存 / @ / 私聊 / 传送 / 屏蔽；

👥 私聊与会话列表 — 会话列表按「公屏 → 在线玩家 → 最近离线」排序，带真实 ID、皮肤头像、在线状态点与未读红点；分会话保存草稿与滚动位置；另有玩家档案详情页；

🔔 通知 — 被 @、被引用、收到私聊时面板顶部弹出横幅（点击跳转原消息并高亮），配套原创提示音，可分别开关并调音量；

🎨 外观自定义 — 主题预设（毛玻璃 / 现代）一键切换；全部界面配色可调并带实时预览；背景模糊、面板宽度 400–600、界面缩放 x0.75–x1.50、圆角风格、消息入场动画；自定义壁纸长边自动降到 1024；

🧹 聊天治理 — 公屏分类过滤（全部 / 仅系统 / 仅玩家）；跨多条消息拖选后 Ctrl+C 一次复制；连续相同消息合并计数；同一发送者 5 分钟内紧凑分组；屏蔽名单可视化；

⚙️ 设置即改即存 — 设置页为 Win11 风格 2×2 磁贴主页（外观 / 聊天 / 隐私与屏蔽 / 关于），所有选项即时生效并立即写盘，无需重启；可选把聊天记录按服务器 / 世界存盘。

[h1=怎么用]

① 打开聊天就是手机面板：顶部「公屏」与系统时间，中间消息列表，底部输入栏；

② 打字回车发送；内容超过一行时输入栏自动长高，仍可用上下箭头在行间移动光标；

③ 发图三种方式：点图片按钮、把图片拖进窗口、复制图片后 Ctrl+V；

④ 点表情按钮打开面板，切「表情 / 颜文字 / 表情包」三个标签页；⑤ 右键任意消息可复制或引用回复；单击头像开档案页，双击戳一戳，右键呼出菜单。

[h1=图片走的是哪条路]

装了 AtomChat 的服务端会优先接管你发的图片：消息里写的是 atomchat-media 短链，其他玩家按需从服务器拉取。服务端没装 AtomChat、hostingEnabled 关掉了、文件超过 maxFileKb、上传失败 —— 任一情况自动回退第三方图床 uguu.se（链接约 3 小时过期）。

想确认实际走了哪条路，看客户端日志：托管成功会有一行 Stored hosted media。服务端托管的媒体默认保留 7 天（retentionDays，0 = 永久），按容量上限自动修剪最旧的内容。

[h1=安装]

支持平台：Fabric 1.21.1 / NeoForge 1.21.1 / Forge 1.20.1（三端功能同源）。

依赖：Fabric 版需 Fabric Loader 0.16.0+ 与 Fabric API，Java 21+；NeoForge 版需 NeoForge 21.1+，Java 21+；Forge 版需 Forge 47+（1.20.1），Java 17。

系统：仅 Windows x64 —— JAR 内只打包了 Skija 的 Windows x64 原生库，Linux / macOS 装上后聊天面板起不来。

安装：下载对应平台的 JAR 放进 .minecraft/mods/；想让服务器托管图片并同步头像，把同一个 JAR 也放进服务端的 mods/。启动游戏后按聊天键（默认 T 或 /）打开；也可以按 Y（默认按键，可在 按键绑定 → AtomChat 里改）直接打开面板并回到上次的页面。

[h1=服务端配置（可选，服主看）]

服务端首次启动会生成 config/atomchat/atomchat-server.json；也可以在游戏内用 /atomchat gui 直接改（OP 2 级，单人存档无需权限；控制台没有可绘制的界面，会提示需在游戏内执行）。改配置的人保存后立即生效，其他在线玩家下次进服时生效。

媒体托管（hostingEnabled 默认开）：maxFileKb 单文件上限 2048 KB；maxTotalMb 媒体库总量 512 MB；maxAvatarTotalMb 头像库 64 MB；retentionDays 保留天数 7（0 = 永久）；uploadCooldownMs 同一玩家两次上传的最小间隔 3000 毫秒。

本服下发（packEnabled 默认开）：packMaxFiles 下发的表情文件数上限 32；packMaxMb 表情总字节上限 8 MB；packName 客户端面板显示的服名，留空则用 MOTD 清洗后的首行；phrases 下发的常用语（最多 20 条、每条 ≤200 字）。

要下发给客户端的表情包放进服务端的 config/atomchat/server-emotes/（与玩家自己收藏的 config/atomchat/emotes/ 分开，单机 / 局域网主机默认不会把自己收藏的表情推给访客）；专用服务器首次构建下发包时，会把旧目录里已有的表情一次性拷贝过去，只拷贝不删除。客户端有硬上限（200 个文件 / 16 MB）。

[h1=兼容性]

✅ Fabric 1.21.1、NeoForge 1.21.1、Forge 1.20.1；

✅ 服务端可选安装 —— 装了才启用媒体托管与头像同步，不装就是纯客户端；

✅ CICode 图片协议与 E33Chat / ChatImage 系互通；ChatHeads、聊天动画类模组兼容；

🟡 花名 / 昵称插件、EasyBot 为尽力识别，无法解析时回退为灰色系统消息；

🚫 Quark 下不显示表情菜单，正在尝试兼容。

[h1=已知限制]

1. 仅 Windows x64，Linux / macOS 无法运行；

2. 服务端没装 AtomChat 时图片走第三方图床 uguu.se（约 3 小时过期）；超过 maxFileKb（默认 2 MB）的文件不会上传服务端，客户端也不会重新压缩；

3. 玩家身份解析是尽力而为，识别不了的会保守归为灰色系统消息；

4. 独立服务器的托管链路尚未实测（目前只在单人 / 局域网主机的服务端侧验过），两个客户端互拉图片也未实测；

5. 功能面小于 E33Chat：暂无私聊侧边栏与搜索（服务端格式模板 chatTemplates / whisperTemplates 已支持，需手改配置）。

[h1=隐私与数据]

⚠️ 你发送的本地图片会被上传到第三方图床（默认 uguu.se），或（服务端开启托管时）保存到你所在服务器的磁盘上，且他人可以保存 / 转发；你的消息也可能被开启了聊天记录功能的玩家保存在本地。请勿发送敏感或私密内容。

模组不上传任何遥测 / 个人信息；图片上传只在你主动选择 / 粘贴 / 拖入时发生；服务端托管只通过游戏连接传输字节，不开放 HTTP 端口。本地配置、头像、壁纸、表情包只存在 .minecraft/config/atomchat/，不会自动同步给别人。

[h1=常见问题]

问：需要装服务端吗？ —— 不需要，纯客户端模组。服务端也装一份才会激活媒体托管与头像同步。

问：表情包存在哪里？ —— 自己的在 .minecraft/config/atomchat/emotes/（默认不限量，png / jpg / jpeg / gif；可在 atomchat-client.json 里用 emoteMax 设上限）；服务端下发的表情在只读的「本服」分区，单独计数。

问：为什么某条消息显示成灰色？ —— 客户端无法确定它是玩家消息时会保守归为系统灰字（常见于昵称插件使用了无法解析的格式）。

问：可以放进整合包吗？ —— 可以，代码为 MIT，无需额外授权；若分发 JAR，请保留仓库中的第三方声明文件。
