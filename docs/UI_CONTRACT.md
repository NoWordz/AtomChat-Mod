# AtomChat UI 回归约定

保留用户确认的功能、视觉和普通回归测试。2026-11-14用户已撤回SHA锁、trust、hook、readonly及其变异门禁要求；本文不再规定强制文件锁。

## 复用与颜色

- 警告/破坏性确认使用原有警告图标与确认按钮红色（UiTokens.dangerColor），取消按钮灰色
- 教程开始、教程说明及HUD/面板编辑器正常主操作保留主题强调色；不能把这个例外套到警告窗
- 对话框复用ConfirmationDialog/ConfirmationSurface/PickerModalPaint的表面、阴影、字号与动效，不另做皮肤
- 设置恢复按钮只恢复当前页签，包括折叠和未滚到的项；取消不改，失败回滚，不删除个人资源
- 恢复调整页签成功时退出编辑器，旧取消快照不能撤销已经确认保存的默认值

## 玩家可见文案

- AtomChat 的简中和英文界面、教程、提示及内置默认反馈省略文案末尾的句号（`。` 或 `.`）
- 保留段落内的句号，以及问号、感叹号、省略号、缩写、链接和格式占位符
- 玩家消息、服务器原文、导入内容与配置中已有的自定义文案保持原样

## 图标与头栏

- 同一按钮家族的图标尺寸、描边、间距及点击区域使用现有token
- 头栏恢复图标复用返回/过滤按钮的adjacentButton与ShellHeader绘制、hover、press、ripple和标题避让
- SVG以实际曲线tight bounds同时计算缩放和居中，不能用控制点外框；禁止按单个图标硬加偏移掩盖错误
- 原生像素检查覆盖返回/过滤/公告/用户/恢复图标，墨迹几何中心误差最多1个输出像素，不能偷偷扩大容差

## 已确认的编辑器与教程

- 四角四边八向缩放，常显8个缩放点，整边可拖；移动使用顶部外侧中央胶囊四向把手，贴顶临时内移
- HUD式九宫格锚点每处一个，不能根据近满高面板的中心位移挤成三个点
- 面板内部真实可交互，外侧空白不关闭；仅还原/保存及已确认短提示，还原本次编辑前几何，Esc取消
- 教程的外侧说明、面板内轮廓聚焦弹簧、不断开的连线、白名单及真实沙盒不能连带回退

## 鼠标点击

- AtomChat 自有离散动作使用当前绘制命中，在按下时给出反馈并执行一次。页面或设置页签动效可由下一次有效按下打断
- 松开只清理反馈。拖动、弹层接管、失焦、切页及关闭时取消反馈，已被 AtomChat 捕获的松开不得穿透到新的页面或控件
- 滑块、滚动条、文本选择及调整手柄在按下时进入跟手状态。键盘、滚轮和原版或第三方控件保留原输入语义
- 支持横拖的预设和关于卡条沿用轻点判定。手势在松开时确认是否选卡，并由卡条消费

## 验证与交付

- 继续运行普通三端test build、targets/JAR/bare及行为/原生像素回归；未跑或跳过不标通过
- 不重录基线、删除回归测试或放宽像素容差来掩盖功能回归
- Fabric CCB 每次部署使用 `tools/deploy_ccb.py`，传入独立审定的前端契约 Git 修订。它执行与 Windows CI 相同的 `clean build frontendContractCheck`，核对实际打入分发包的设计和准入清单，通过后备份并替换 CCB 的 AtomChat JAR。CCB 须已装同一构建输入的 AtomLib，部署时关闭实例。
- SHA清单、独立trust、pre-commit、Gradle uiContractCheck和Windows只读门禁已按用户新指令取消，不再继续建设或激活

### 正式设置场景

| 页面 | 当前正式场景 | 仍缺正式场景 |
| --- | --- | --- |
| 设置首页 | 作为历史和托管的导航经过 | 首页卡片指针、分栏、入口与恢复 |
| 外观 | — | 预设卡片、壁纸和气泡选择、材质与颜色、布局和 HUD 编辑、动效与性能设置 |
| 聊天设置 | 历史页签的导航、折叠、数字编辑、开关、清理确认与声音 | 消息、通知、聊天特效三个页签的独立交互和像素 |
| 隐私 | — | 屏蔽、服务器资源包和列表操作 |
| 关于 | 第三方卡片的全局悬停、按压和折叠，标题墨色，滚轮分流、限位、横拖、Logo 链接和性能模式即时响应 | 模组信息链接、清缓存、调试开关与性能开关的完整点击流程 |
| 服务器配置 | 托管页签的导航、折叠、输入、开关和声音 | 整合包、快捷语、模板和说明、表情资源和图片预览 |

聊天大厅、公聊和私聊、资料详情、聊天 HUD、横幅及教程在这份设置契约场景之外。已有源码边界、普通测试和离屏渲染依各自范围继续运行。About 场景运行生产设置控制器并拦截打开链接的调用，Screen 的输入分流另由源码边界审查。
