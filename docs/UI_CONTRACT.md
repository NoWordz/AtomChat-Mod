# AtomChat UI 回归约定

保留用户确认的功能、视觉和普通回归测试。2026-11-14用户已撤回SHA锁、trust、hook、readonly及其变异门禁要求；本文不再规定强制文件锁。

## 复用与颜色

- 警告/破坏性确认使用原有警告图标与确认按钮红色（UiTokens.dangerColor），取消按钮灰色
- 教程开始、教程说明及HUD/面板编辑器正常主操作保留主题强调色；不能把这个例外套到警告窗
- 对话框复用ConfirmationDialog/ConfirmationSurface/PickerModalPaint的表面、阴影、字号与动效，不另做皮肤
- 设置恢复按钮只恢复当前页签，包括折叠和未滚到的项；取消不改，失败回滚，不删除个人资源
- 恢复调整页签成功时退出编辑器，旧取消快照不能撤销已经确认保存的默认值

## 图标与头栏

- 同一按钮家族的图标尺寸、描边、间距及点击区域使用现有token
- 头栏恢复图标复用返回/过滤按钮的adjacentButton与ShellHeader绘制、hover、press、ripple和标题避让
- SVG以实际曲线tight bounds同时计算缩放和居中，不能用控制点外框；禁止按单个图标硬加偏移掩盖错误
- 原生像素检查覆盖返回/过滤/公告/用户/恢复图标，墨迹几何中心误差最多1个输出像素，不能偷偷扩大容差

## 已确认的编辑器与教程

- 四角四边八向缩放，常显8个缩放点，整边可拖；移动使用顶部外侧中央胶囊四向把手，贴顶临时内移
- HUD式九宫格锚点每处一个，不能根据近满高面板的中心位移挤成三个点
- 面板内部真实可交互，外侧空白不关闭；仅还原/保存及已确认短提示，还原本次编辑前几何，Esc取消
- 教程的外侧说明、面板内轮廓聚焦弹簧、不断开的连线、白名单及真实沙盒不能连带回退

## 验证与交付

- 继续运行普通三端test build、targets/JAR/bare及行为/原生像素回归；未跑或跳过不标通过
- 不重录基线、删除回归测试或放宽像素容差来掩盖功能回归
- 本轮候选先由主代理独立复审，放行后才执行已授权三实例备份部署与独立回读；不启动游戏、不提交/推送/发布
- SHA清单、独立trust、pre-commit、Gradle uiContractCheck和Windows只读门禁已按用户新指令取消，不再继续建设或激活
