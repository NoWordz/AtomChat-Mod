**设置页里有什么、怎么换头像和壁纸、以及配置文件里那几十个键分别是什么。**

## 设置页

底部第三个标签 **设置**，是一个 Win11 风格的 2×2 磁贴主页：**外观 / 聊天 / 隐私与屏蔽 / 关于**，点进子页。

所有选项**即时生效并立即写盘，不需要重启游戏**；颜色类选项带预设色板、`+` 自定义拾色器和实时预览色块。

## 外观

| 选项 | 说明 |
|---|---|
| 主题预设 | `毛玻璃`（frosted）/ `现代`（modern）一键切换；预设只是把下面这些单项一次性写一遍，之后仍可单独改 |
| 背景模糊 | 面板背景高斯模糊；**与自定义壁纸互斥** |
| 面板不透明度 | 0–100%，模糊开或关都作用于底色 |
| 面板宽度 | 400–600（设计像素） |
| 界面缩放 | x0.75 – x1.50，整套 UI（含布局与命中测试）一起缩放 |
| 消息入场动画 | QQ 式横向滑入 + 淡入 |
| 动画总开关 | 关掉装饰动效（进出场、页面推入、戳一戳、滚动吸附）；悬停高亮这类**功能性反馈不受影响** |
| 双击头像戳一戳 | 开关 |
| 全部界面配色 | 面板背景 / 自己的气泡 / 他人的气泡 / 气泡文字 / 次要胶囊 / 主次文字 / 卡片 / 描边 / 强调色，每项带实时预览 |

> `圆角风格`（大 / 中 / 小）目前**没有设置项**：由主题预设写入，想手动改就编辑配置文件里的 `cornerStyle`。

### 自定义头像

`外观 → 自定义头像` → 选图 → 进入裁剪器：

- **拖动**平移图片，**滚轮**围绕取景框缩放，**双击**重置；
- 输出为 256 像素的方形 PNG，存在 `.minecraft/config/atomchat/avatar/`；
- 同一服务器上装了 AtomChat 的玩家会**自动拿到你的头像**（换头像即时广播刷新）；对方没装 / 服务器关了托管时，静默降级为皮肤头像。

### 自定义壁纸

`外观 → 自定义壁纸` → 选图 → 同样的裁剪器交互。图片会降采样（长边 ≤ 1024 像素）后存进 `.minecraft/config/atomchat/wallpaper/`，支持 `png` / `jpg` / `jpeg` / `webp`。

壁纸与背景模糊**互斥**；两者都在时以壁纸为准，用`面板不透明度`压暗壁纸以保证文字可读。

## 聊天

| 选项 | 默认 | 说明 |
|---|---|---|
| 图片消息 | 开 | 关掉后不下载不缓存，显示绿色 `[图片]` 占位 |
| 时间戳分隔 | 每 5 分钟 | 首条消息始终显示；`0` = 关闭 |
| 防刷屏合并 | 开 | 连续相同消息合并为一条并显示次数 |
| 紧凑消息分组 | 关 | 同一发送者 5 分钟内的连续消息只保留第一条的头像与名字 |
| 保留聊天记录 | 关 | 开启后按服务器 / 世界存到 `.minecraft/config/atomchat/history/`（JSONL），重进同一服务器恢复 |
| 历史保留天数 | 7 | `0` = 永久 |
| 通知（@ / 引用 / 私聊） | 开 | 横幅与音效可分别开关，另有总音量 |
| 传送模式 | `auto` | 在 `/tp` / `/tpa` / `auto` 之间循环；`auto` 会探测服务器命令树 |

## 隐私与屏蔽

- **屏蔽名单**：可视化列表（头像 + 名字 + 一键取消）；
- **隐藏被屏蔽玩家的消息**：默认开。关掉后公屏仍可看到其消息，但私聊保持屏蔽；
- **接收本服下发内容**：默认开。关掉后不再向服务器请求表情 / 常用语 / 服务端标识，并立即清空已加载的视图。

## 关于

版本、许可证、仓库链接、第三方组件（Skija / Skia / FlatLaf），以及两个操作：

- **清除图片缓存** —— 只清 `<游戏目录>/atomchat-data/` 里的图片缓存，**不影响**表情包 / 壁纸 / 头像；
- **调试模式** —— 打开后会把头像取色采样写成 PNG 到 `.minecraft/config/atomchat/debug/`，排查头像颜色问题用。

## 配置文件与数据落点

游戏内能改的都能改，但想批量编辑或提前配置，直接改文件即可。主配置：**`.minecraft/config/atomchat/atomchat-client.json`**（首次启动自动生成）。

> 手改文件后需要**重启游戏**。唯一例外是 `chatTemplates` / `whisperTemplates`：它们在每次打开聊天界面时重读。

| 路径 | 内容 |
|---|---|
| `config/atomchat/atomchat-client.json` | 客户端主配置 |
| `config/atomchat/avatar/` | 自定义头像（256px PNG） |
| `config/atomchat/emotes/` | 你自己的表情包（默认不限量，`emoteMax` 可设上限） |
| `config/atomchat/server-emotes/` | **仅服务端**：下发给客户端的分发源 |
| `config/atomchat/wallpaper/` | 自定义壁纸 |
| `config/atomchat/history/` | 聊天记录（默认关，按服务器 / 世界分文件） |
| `config/atomchat/debug/` | 调试模式下导出的头像采样 PNG |
| `<游戏目录>/atomchat-data/` | 图片缓存、服务端下发的包、他人头像数据（500 文件 / 100 MB / 7 天未用自动清理） |

服务端自己的配置与数据在服务端游戏目录下，见 [服主手册](服主手册)。

## 客户端配置全表

| 键 | 默认值 | 说明 |
|---|---|---|
| `panelWidth` / `panelHeight` | `440.0` / `780.0` | 面板尺寸（设计像素，内部再乘界面缩放） |
| `panelOpacity` | `0.93` | 面板背景不透明度 0–1 |
| `blurEnabled` | `true` | 背景模糊（与壁纸互斥） |
| `uiScale` | `1.0` | 界面缩放 x0.75–x1.50 |
| `animationEnabled` | `true` | 装饰动效总开关 |
| `messageEntryAnimation` | `true` | 消息入场动画 |
| `avatarPokeEnabled` | `true` | 双击头像戳一戳 |
| `hideBlockedMessages` | `true` | 被屏蔽玩家的公屏消息是否直接丢弃 |
| `cardTint` | `0.235` | 卡片 / 面板框架的表面色调；预设会写这个值 |
| `cornerStyle` | `"large"` | 圆角风格：`large` / `medium` / `small` |
| `themeName` | `""` | 上次套用的主题预设（`frosted` / `modern`） |
| `panelBgColor` | `0xEE16191F` | 面板背景色 |
| `panelOutline` / `panelOutlineColor` | `true` / `0xFFFFFFFF` | 白色手机式描边开关与颜色 |
| `ownBubbleColor` / `bubbleTextColor` | `0xFF1E90FF` / `0xFFFFFFFF` | 自己气泡的底色 / 文字色 |
| `otherBubbleColor` / `otherBubbleTextColor` | `0xFF2C3E50` / `0xFFFFFFFF` | 他人气泡的底色 / 文字色 |
| `textPrimaryColor` / `textSecondaryColor` | `0xFFFFFFFF` / `0xDCAAAABA` | 界面主文字 / 次要文字 |
| `secondaryCapsuleBg` / `secondaryCapsuleText` | `0x962C3E50` / `0xDCAAAABA` | 系统消息、时间戳、引用胶囊共用的胶囊配色 |
| `cardColor` | `0xFFFFFFFF` | 卡片表面色 |
| `accentColor` | `0xFF4A90E2` | 强调色（发送按钮 / 引用条 / 滚动条等） |
| `imageMessagesEnabled` | `true` | 是否接收并渲染图片消息 |
| `timestampIntervalMinutes` | `5` | 时间戳分隔间隔（分钟），`0` = 关闭 |
| `antiSpamEnabled` | `true` | 连续相同消息合并计数 |
| `compactMessagesEnabled` | `false` | 同一发送者 5 分钟内的紧凑分组 |
| `mentionBannerEnabled` / `mentionSoundEnabled` | `true` | 被 @ 或被引用时的横幅 / 音效 |
| `whisperBannerEnabled` / `whisperSoundEnabled` | `true` | 收到私聊时的横幅 / 音效 |
| `notifyVolume` | `1.0` | 通知音总量 0–1 |
| `mentionRequireAt` | `false` | `true` = 只有显式 `@名字` 才算提及；`false` = 裸名字也算 |
| `serverPacksEnabled` | `true` | 是否接收服务端下发的表情 / 常用语 / 标识 |
| `emoteMax` | `0` | 自己表情包的数量上限，`0` = 不限量；改完重开聊天界面即生效 |
| `chatHistoryEnabled` / `historyRetentionDays` | `false` / `7` | 保留聊天记录 / 保留天数（`0` = 永久） |
| `teleportCommandMode` | `"auto"` | 传送命令模式：`auto` / `tp` / `tpa` |
| `quickPhrases` | `[]` | 常用语（最多 20 条、单条 ≤256 字）；首次生成时会种入一条 `/atomchat gui`，删掉不会回来 |
| `guiTipSeeded` | `false` | 上面那条种子是否已种过（内部标记） |
| `blockedPlayers` | `[]` | 屏蔽名单（真实玩家名） |
| `chatTemplates` / `whisperTemplates` | `[]` | 识别非标准聊天格式的模板，占位符 `{name}` `{display_name}` `{prefix}` `{suffix}` `{sep}` `{content}`；改完重开聊天界面即生效 |
| `debug` | `false` | 调试输出与头像采样 PNG |
