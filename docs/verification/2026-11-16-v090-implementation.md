## 实现范围

- 接收入口保留实际投递的原生身份、可见过滤正文和组件；身份不明的系统通道不再提前运行通用按名猜测。HUD 汇合结构解析、组件身份、已确认格式、显式模板和末级文本兜底。
- 未识别的根翻译语义先保持 UNKNOWN；允许组件、学习格式与显式模板解释。仍无依据的陌生翻译消息保留原文，不交给弱文本猜测绑定玩家。明确系统语义仍排除。
- 发送者参数中的玩家实体 UUID 优先于昵称查询；命令账号与显示组件分开。矛盾的明确身份线索产生冲突结果，阻止后续弱识别重新认领；跨服同名的实际 UUID 不被本服同名账号覆盖。
- 原版/队伍翻译参数、字面包装中的唯一聊天节点、节点自身尾部及有效继承样式保留。原生 RAW 渲染器把整行放在发送者字段时，避免整段正文进入姓名；渲染器省略的正文不会从原生消息偷偷恢复。
- 已确认身份、显示别名、精确格式关系和已观察到的皮肤属性按服务器地址或单人世界目录隔离保存。昵称歧义、UUID 冲突不按最后一次记录强行绑定；弱文本命中不用于自我训练。
- 学习数据放在 `atomchat/cache/recognition/<服务器键哈希>.json`，IO 在后台执行，旧连接/清除前的回调不能重新发布。清除 API 为 `RecognitionMemory.clearCurrent()`；退出游戏后删除该缓存目录也可清除学习，不影响聊天历史。
- 公共与私聊发送保留稳定气泡 ID。原文关联优先于渲染后的正文；仅有相同文字不能吞掉其他发送者/会话的消息。10 秒后显示未确认，关联最多保留 120 秒、32 条；迟到校正需明确原文依据。没有原文依据的任意插件重写不能伪造确认。
- 不确定的皮肤查询不冻结为成功缓存，已知 UUID 不借用其他 UUID 的同名皮肤；连接切换清空会话皮肤缓存。按服保存的是实际观察过的纹理属性，不是根据离线昵称生成的身份。

## 服务端配置页

- `/atomchat gui` 直达已有 AtomChat 主面板中的非根配置页。旧的三个原版 `ServerConfigScreen` 已移除；设置首页不新增入口卡片，已保存导航不把此页当作再次打开入口。
- 顶部为托管、资源包、常用语三类 chip；使用既有卡片、开关、字段表面、头栏、确认弹窗、按钮、字体和主题 token。没有新增 SVG。窄面板标题换行，英文分类使用可辨识短标签。
- 三类共享独立服务端草稿。底部文字保存按钮固定，提交时冻结编辑；失败保留草稿，成功仍在当前分类。
- 既有 Result 编码不改。成功回执后经已有命令取得新快照，再采用服务端确认值与版本；不凭本地版本加一猜测其他管理员状态。
- 返回/Esc 走已有未保存确认，然后返回原世界/私聊。服务端配置返回避开聊天清理逻辑，保留草稿、引用槽、滚动与历史展开。
- 写入时重新检查管理权限；单人例外只适用于实际主机。配置先写候选文件，成功后才发布运行配置和成功回执，失败不提前修改缓存对象。

## 尚未满足或未验收

1. 没有实际 Paper/Youer/TrChat 群组服或用户故障配置；没有真实插件回放。上述单测和静态源码分析不能等同于插件兼容率。
2. 代表性真实场景的具体发行版本、样本分母与完整头像结果尚未冻结，不能公布“自动识别达到 90%”。手工模板也没有混入自动成绩。
3. TrChat 冷缓存、首次陌生离线跨服玩家，如果最终组件没有身份及皮肤线索，客户端无法恢复缺失的实际资料。此关键项仍未满足，没有用默认头像、同名正版 UUID 或暖缓存替代。
4. 原样纯文本里不可辨别的公告与玩家消息、缺少身份关联的任意私聊格式/重写，不靠增加词表宣称解决；无明确依据时保留原消息或未确认发送状态。
5. 代理入口地址不证明各子服共享身份和皮肤命名空间；未传递子服边界或资料时，不宣称所有后端切换与皮肤变化都能自动恢复。
6. 真实游戏的命令入口、权限撤销、网络延迟、IME/输入焦点及完整 UI 交互仍需验收。没有启动游戏、服务端或群组环境。
