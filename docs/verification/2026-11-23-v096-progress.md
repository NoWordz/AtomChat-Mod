## 审计修正

原阶段独审的字宽、名字样式、组首折叠和原始记录问题已修正。全局 SkiaFontRenderer/PlainText 保持原样，聊天局部复用准确 Font 身份测宽；没有通过改变普通设置布局来满足聊天测量。

字体/消息实现代理交付91文件后，主流程逐文件对照原阶段快照整合。独审找到 Fabric reload 重载目标错误、每帧全文字体扫描和状态后缀首帧漏字，均修复：明确 private apply descriptor、共享可见 viewport 准备、HUD 实际退场集合、共用状态名字源。实际生成 refmap 也已核对为两参数 void 的 method_51614。

完整测试发现新 glyph glGetTexImage 与既有头像安全读回约定冲突，改为自有 FBO 的已知矩形读回，没有放宽原检查。新增真实 GL 回归检查单色 coverage 像素、FBO/PBO/texture/pixelstore 恢复。隔离 profile fixture 补齐新接口，保留原真实 facade 与断言。

主流程另外修复关闭历史时漏净化、连续撤回任务覆盖未完成签名，以及未知字体 ID 使查找缓存无限增长。均有旧实现失败与修后通过的证据；未完成净化批次只在提交前合并，成功落盘/清理后释放，普通保存仍尊重历史关闭开关。字体查找缓存有界，不关闭 Minecraft 所有的 FontStorage。

独审报告及增量复核位于 `build/v096/final-review-font.md`、`final-review-font-fixes.md`、`final-review-messages.md`。原阶段报告也保留。最后队列修正已由独审解除阻断；报告没有把单测、源码检查或隐藏 GL 当作完整游戏验收。
