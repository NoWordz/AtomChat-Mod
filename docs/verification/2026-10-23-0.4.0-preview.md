# 0.4.0-preview：设置收尾、实时面板模糊与四组目录

## 实现范围

- HUD 与面板横幅保留原有不透明浮动通知材质、下落动画和共享队列；本轮只修复跳转纸飞机的强调色对比色，不再给横幅套卡片透明度、局部背景模糊或页面切换动画。
- 面板背景模糊从旧的每两帧/静止 500ms 缓存改为每帧读取当前画面。
- 双向步进选择器的左右箭头分别按 action 维护 hover 权重，并使用全局 hover 渐变。
- `atomchat/` 顶层收为 `client/`、`cache/`、`server/`、`backups/`。`client/` 在首次启动创建 avatar、banner、wallpaper、emotes、presets、history；缓存、服务端和备份目录按需生成。
- 迁移兼容旧 `config/atomchat`、`atomchat-data` 与上一版扁平目录。当前图片优先，冲突、链接、损坏和失败保留来源并提示。
