# AtomChat 0.9.8 集成验证

开发基线为 0.9.7 主线 `2b4d3249`，构建输入为发布归档中的 AtomLib 0.7.1。验收覆盖 Fabric 1.21.1、NeoForge 1.21.1、Forge 1.20.1。工作证据保存在 `D:/AtomChat-Backups/2026-11-26-v098`。

## 可复查的分支与实机证据

- Java 预览接口与 JEI 示例的用法见 [开发指南](../JAVA_UI_API.md)。在隔离 Fabric CCB 中从工作台卡片打开 JEI 真配方页，按 Esc 返回同一个 AtomChat 面板。再通过真实指针坐标验证输入栏按钮、导航页签、设置首页入口和附件设置组。记录在 `jei-live/integrated-fabric-controls`。
- [兼容与联动调查](2026-11-26-v098-mod-compatibility.md) 区分实际实例的加载清单、历史已复现问题和待实机的新组合。
- 特殊卡片和公屏头像含三端回归、原生离屏对照、隔离服务端的权限和收包检验。StellarRTP 有本轮协议实测，EssentialsX、HuskHomes 复用上轮隔离服收包并重跑本轮的适配。记录在 `cards`。
- [缓存、帧时与三档画质](2026-11-26-v098-render-performance.md) 保留冷开、静止、滚动、切页和 HUD 的测量。对照图和 JFR/CSV 归档位于 `performance`。

## 中间构建与回归

首轮集成的三端全量 JUnit 共 7,205 项，56 跳过，除三端相同的旧模糊缓存源码断言外均通过。源码检查修订为验证生产路径是否在纹理失效、画质、强度或目标与采样范围变化时做完整刷新。各端 11 项针对同一复用契约的测试随后通过。实际日志、XML 及每端计数位于 `integration-1`。

独立交叉审查复现了附属回调离开私聊后仍可提交旧草稿，以及收到的卡片可指定本地回调的入口。修订把编辑与提交绑定到原会话和当前回调，同时在三端卡片接收边界过滤本地回调。根页签恢复及设置行、组 ID 也加了回归。三端定向通过记录位于 `review-fixes`。

## 现有设置场景的差异定位

独立回放使用 0.9.7 已审定的设置场景文件。第一次略过源码阶段的定位过程缺少正式运行时配置，历史页在第 35 帧进入备用路径。第二次仅将正式发布的 0.9.7 运行时配置用于开发回放，三端各运行 196 帧，均只有相同 33 张窄屏、浅色、英文样本存在像素差异。

Fabric 对照在同一运行器里只替换 0.9.7 发布版 `SkiaFontRenderer` 类，196 帧恢复逐项一致。三端 33 张差异都落在 320×900 图像的英文页签文字区域，变化包围盒在 x=39–183、y=131–150 内。逐帧比较确认交互状态、时间、观测值、声音及资源字段一致。拟更新的场景文件逐字节保留了 163 个其他样本和原有零像素容差，只替换上述 33 张图片。原图、差异表、当前图、只替换字体的对照和拟审样本均保存在 `old-font-counterfactual`。
