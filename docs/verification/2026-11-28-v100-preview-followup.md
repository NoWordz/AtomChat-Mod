# AtomChat 1.0.0-Preview 续更审计

## 构建与交付

Gradle 在执行构建的工作树里生成 JAR。本地交付放到主工作区 `D:/AtomChat-Main/platforms/<目标>/build/atomlib-consumer/libs/`，Fabric、Forge、NeoForge 分别进入各自的目录。 [三端路径与摘要回执](D:/AtomChat-Backups/2026-11-28-v100-preview-followup/platform-libs-delivery.json)

Windows 正式本地构建使用以下入口。命令从 Preview 源码工作树执行，传入当前构建对应的已审定 Git 修订和项目固定的 AtomLib Maven 输入：

```powershell
python tools/frontend_contract_ci.py build-local "$mavenRepo" --reviewed "$revision" `
  --java17 "$jdk17" --java21 "$jdk21" --delivery-root "D:/AtomChat-Main"
```

需要用已经备好的依赖时可加 `--offline`。每端通过正式构建和 JAR 检查后，就把可安装包放到主工作区对应的 `libs`。只构建 Fabric 时加 `--target 1.21.1-fabric`，并传入 `--java21`。单独用 `deploy_ccb.py` 构建部署时同样传入 `--delivery-root "D:/AtomChat-Main"`。

## 性能独审

两位 GPT‑6.2‑Astra High 分别检查渲染和 HUD，以及收包、保存和后台任务。基线源码为 AtomChat `e586d360`（`95fdaef3` 仅补文档），已部署的 AtomLib 运行包对应 `bfcca160`。

516 现场同次运行中，公屏、设置、导航重复切换的面板耗时 P95 分别从稳态的 10.19、7.48、7.87 ms 到转场的 23.87、15.36、22.95 ms。这些数字是面板计时。后续四个常规 `client_work` 窗口的 P95 为 0.017–0.028 ms。转场、资源重载、进世界后的多模组任务和网络重置需要分开归因。客户端确认的断开异常为套接字读到 `Connection reset`，重置发起方仍未知。 [上轮现场与配套记录](2026-11-27-v100-preview-baseline.md#516-原服复测与现场问题)

## 反哺 AtomLib

| 优先级 | 候选 | 建议的复用方式 |
| --- | --- | --- |
| 优先 | 借用物品纹理的窄 GL 状态保护 | `bfcca160` 已有 GL 桥、状态集、纹理释放回调及测试，0.7.2 候选分支尚无该入口。独立移植到库候选，先核对通用绘制状态回滚和旧消费者回退。固定同一 Preview 只换库的 Fabric 钓竿测试已有收益和像素零差异，Forge、NeoForge 有待确认提速方向 |

| 其次 | 主题层级、材质令牌、图标规范 | 通用化面板、卡片、控件三个表面角色，提供明暗预览夹具；沿用 AtomLib 的 `ControlTokens`。SVG 以实际曲线边界缩放、居中和做像素验证，选入具体图标时沿用 Tabler、Lucide、Feather 原有许可 |
| 单独验证 | 可中断页面与原生资源生命周期 | 复用中断当帧、设备或上下文变更、同一资源所有权和释放的测试思路。先从现有 `PageMotion`、`RegionMotion` 和 `ResourceScope` 选最小落点，用第二个消费者确认 API 形状 |

## UI 核对线索

- 青柠原面板与卡片同为 `#FFFFEC`。典雅、黑鸦、枢纽的原次级胶囊与各自面板同色，活力的原胶囊与卡片同色。重新点选内置主题时应用新配色，已存的手调颜色沿用原值
- 用户截图的设置卡片在面板底部贴着固定视口，被裁成一条横线。顶部上栏和设置页签下缘用同类视口裁切。验收要检查滚动中两端渐隐、滚到头时对应端恢复、固定栏及点击区域一致，玻璃的颜色层和模糊遮罩同时渐隐
- 简中和英文的玩家文案按项目契约省略末尾单个句号，段落内标点和数据原文保留
