## 发现与实现

1. **普通文字测宽串用字体。** `SkiaFontRenderer.getStringWidth` 旧键为字号，先画同字号常规或宽体的顺序分别产生 179.18 px 少算、175.93 px 多算。旧版定向 JUnit 两方向均实际失败。按字体实例分桶，热命中不再申请字号键或查询 Skija 字号。继续限制 16 个字体桶、每桶 4096 项。清文字形状缓存时同步清测宽。富文本已有独立的按实例测量路径。
2. **诊断复用读到旧模糊底图。** 实际 OpenGL 将黑底上的面板移到白底，改宽后仍绘出黑色，断言期望 255，旧行为实际为 0。复用键跟踪帧缓冲实例、FBO、物理大小和采样矩形。质量、强度、HUD 借用和资源失效仍触发重绘。窗口或画面裁切间的复用只在物理采样条件相符时成立。普通着色路径继续捕获当前画面。
3. **平衡档高强度背景模糊。** 未裁切 GL 背景在强度 ≥200% 时由 1/2 降到 1/3，每维的实际比率仍用于五轮 Kawase 偏移。极致、弱模糊、裁切路径、Skija 卡片独立模糊和 UI 像素网格沿用原路径。HUD 蒙版通过同一背景采样入口。容量按二次幂分配，实际内存下降幅度随尺寸变化。219×141 的回归夹具，平衡容量纹素从 16,384 降为 8,192。
4. **平衡档大面板阴影。** 仅当面板覆盖至少 262,144 个物理像素、矩阵为 1×–2× 等比轴向变换时，将九宫格阴影贴图从 2× 降为 1.5×。保留实尺寸透明内孔的差集裁切、阴影层的颜色和模糊半径、对齐后以设备像素绘制的缓存。小面板沿用 2×，逐字节一致。HUD、卡片、文字阴影保持既有策略。

GPU 隔离探针复用生产着色器，将 1/2 与 1/3 按 ABBA 运行，每段预热 30 次，再记 120 组提交和 GPU 纳秒。设备像素范围 480×860、900×1500、1440×2160 时，1/2→1/3 的 GPU 中位数分别为 0.02355→0.01701、0.05323→0.02973、0.10866→0.05437 ms。这一组覆盖五轮通用模糊 pass；实际 CCB 另计捕获、边缘扩展、合成、Skija 和游戏。

保留现有 OpenGL 几何验收标准。219×141 对比极致／新平衡的 10–90% 背景过渡，200% 为 58.00／58.50 px，300% 为 87.50／86.50 px。HUD 与面板测得相同跨度，帧缓冲 alpha 原断言保留。

含阴影的生产路径确有较低采样密度和冷烘焙收益。CCB 端的绝对帧时在轮次间波动，关面板控制组与未改变采样的极致和性能档也一起变慢。只改模糊和缓存的中间候选在若干片段反而更快。保留这些实际差异和长帧证据，整帧可感知收益仍待同负载重复实机确认。分段记录中，平稳滚动的列表绘制通常小于模糊与提交合成之和，媒体异常长帧有 GL 桥入口墙钟增长。冷开尖峰主要位于首帧绘制／提交，构造期间配置重载另记在 ScreenLifecycle。当前没有足够证据把长帧归因给单项缓存或 JIT。

最终候选收集 12,505 个游戏循环间隔，复测基线 18,022 个。原图两侧各 36 张。抽查暗色 2× 静止媒体的同屏裁剪，测试图片和相邻纹理边的 141×55 区域逐 RGB 像素相同，公屏标题高亮主体的位置和 399 个像素的掩码相同。字缘背景混色有差别。高频像素缩图另由 ImageQuality 原生用例验证，真实照片和动态帧在当前 CCB 的观感仍需用户实测。画质方案保留当前 GPU 离屏合成。

## 验证结论和剩余范围

- Fabric 定向 78 项，NeoForge 63 项，Forge 63 项，均零失败和零跳过。另跑最终阴影原生 GPU／像素探针一项，零失败和零跳过。Fabric 开启原生 blur、GPU 和导航探针选项。覆盖中英语言实例往返、原版字形 provider、原生位图、阴影、模糊像素、文字阴影和诊断录制。
- 阴影前的 Fabric 宽度回归和几何回归均有实跑红灯。几何探针初版坐标曾读超出帧缓冲，初版日志仅作排错记录。修正后先验证白底，再恢复旧复用条件，得到期望 255 实际 0，随后以同一夹具验证修复。
- `verify_targets`、`gen_seams`、`bare_scan` 和 Fabric 候选 JAR 断言通过。正式独立前端契约有两类阻断，本工作树 Loom 映射 JAR 内容摘要与审定摘要不一致，缺独立审定场景时场景检查也拒绝执行。该回放 JAR 只用于隔离联测，定向构建命令明确排除了这两项契约任务。三端全量、主线 ModeDCadenceTest 更新由集成分支核对。
- 当前机器实际 CCB、真实服务器重连换世界、运行中强制换新 GL context、Forge 装 Chloride 的实点快切、用户画面对照和 JEI 真实右键闭环仍待相应实机确认。Alpha、像素、局部 GPU 或闭环夹具的结论只适用于各自覆盖范围。
- 可复查交付位于工作树 `build/v098-perf/v098-perf-evidence.zip`，含原始 JFR、逐帧 CSV、三档前后原图、测试 XML、命令日志、JEI staging 核对和本地候选。用于矩阵的最终候选 JAR SHA-256 为 `098a5724cfa226b9059489789cf62cff71e310e316b7eb93fe22a406545324db`。`paired-media.png`、`paired-text.png` 为对照图，原图在各运行目录保留。
