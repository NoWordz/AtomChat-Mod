# AtomChat v0.7.0：动画、壁纸与主题优化

状态：2026-11-10，用户经 13 轮 grill 确认产品决策；尚未实施或验收。

## 1. 切页与中断

- 入场、出场同时进行，不等待旧页退完再进入新页。
- A→B 未结束又触发 C 时，从当前画面连续转向 C；不硬切、不排队、不从固定起点重播。
- 导航操作立即生效，退场内容不接收输入。目标页的命中区域跟随实际绘制位置，绘制与命中共享几何。
- 滑动模式区分前进与返回方向；缩放模式配合淡入淡出。
- 标题、返回按钮立即切换为目标页状态，不保留旧页可操作的 chrome。
- 全局关闭动画时，页面与底栏均立即切换。
- 中断时的资源持有、退场层合并与释放策略由实现阶段验证；不得无限叠加退场页或保留失效 GPU 对象。

## 2. 底栏连续形变

- 聊天页进入导航页：输入框外形连续变为导航底栏。
- 切成导航时立即取消输入焦点、收起补全框，保留草稿；导航按钮立即可用，命中跟随画面。
- 返回聊天恢复输入框；只有离开前正在输入时才恢复输入焦点。
- 导航页进入“外观／动画／关于”等具体设置页：底栏两端快速向自身中心收拢，同时淡出，最终完全消失。用户在实施阶段补充确认：设置首页保留底栏。
- 具体设置页返回导航页：从同一中心反向展开；中途反转也从当前状态接续。
- 底栏固定采用上述形变；内容仍遵循现有全局缩放／滑动风格。

## 3. 性能范围

- 包含首次打开、首次进入各页、连续切页、快速反向返回，不只验收热缓存。
- 用真实游戏帧耗与操作表现验证；检查动画中的资源创建、布局、绘制与缓存失效。
- 壁纸生成允许显示明确的短暂加载状态，但不能阻塞交互或影响后续切页。
- 不以离屏测试、平均 FPS 或构建通过代替实机动画验收；具体性能基线待测量，不预设虚假的通过阈值。

## 4. 默认主题

- 蓝色强调色保持不变。
- 背景与卡片改为黑色系，突出透明感，同时保持形状和层次可辨。
- 以约 40%–60% 不透明度制作实际界面对比；这是不透明度，不是透明度。
- 透明层叠后的阅读效果需在亮、暗壁纸与实际游戏背景下验证。
- 具体色值与背景／卡片之间的透明度分配由实图确认，不能仅凭数值宣布观感达标。
- 既有自定义配色不得被无条件重置；历史默认配置如何识别与升级需先核查配置结构。

## 5. 阴影专项

- 调查并修复聊天页“回到最底部”按钮阴影出现明显硬边框的问题。
- 审计同类浮层、按钮、底栏、卡片的阴影裁剪与合成问题；具体缺陷清单以代码和渲染证据为准。
- 手机面板外侧增加软阴影，体现悬浮于屏幕上的层次。
- 半屏模式在可见边缘呈现软阴影。
- 阴影应自然衰减，不出现矩形截断或伪装成阴影的明显描边；检查动画中的裁剪边界。

## 6. 可调边框

- 用粗细调节替代“禁用描边”开关。
- 范围 0–4，单位为随 UI 缩放的逻辑像素；0 表示无边框。
- 新配置默认 3；已有配置开启描边则保留原粗细，原来关闭则迁移为 0。
- 边框绘制、背景内缩、模糊捕获必须使用同一有效粗细，避免接缝。
- 调节步长与控件复用由现有设置交互确定，不另造一套控件。

## 7. 壁纸预设

- 壁纸与主题完全独立，不提供“应用整套搭配”，应用主题不替换壁纸。
- 仅首次使用设置默认壁纸；升级不得覆盖已有用户选择。
- 预设选择沿用主题预设的交互设计，具体复用点先核查现有实现。
- 简约款：低对比渐变、几何色块。
- 艺术款：抽象流体、光带、层叠曲面，现代克制。
- 实施阶段用户否决首批大面积模糊、仅蓝白的壁纸。壁纸使用独立多色盘，包含暖陶、绿、紫红、琥珀／沙金等；艺术款必须有可辨曲面边界、褶皱和高光，不能用整幅雾化替代细节。主题蓝色强调色不约束壁纸色系。
- 所有壁纸均为静态；SkSL 用来生成复杂艺术图，不持续播放动画。
- 选中或尺寸变化时按需生成／缓存，具体失效键、缓存格式和生命周期须验证。
- 包含少量明亮款，用于检验黑色透明卡片的可读性；首批数量与具体图案待实际样张确定。

## 8. 架构边界

- v0.7.0 不迁移 Yoga，保留现有布局体系。
- Yoga 迁移后续单独评估；布局引擎不是页面导航、动画或业务状态的整体替代品。
- 本版只为上述功能做必要调整，不以专项名义扩展成全框架重写。
