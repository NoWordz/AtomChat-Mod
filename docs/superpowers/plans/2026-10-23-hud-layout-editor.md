# 0.4.0-preview UI 与目录收尾

用户已授权实施、三端部署；不增加提交、推送、公开发布或启动客户端。沿用 Skija 直画及现有主题，不引入 UI 框架。

- 设置侧：三种循环动作（头像样式、页面动画、传送命令检测）使用双向步进选择器，值在右、描述在下；AUTHORS 行不再绘制将两张卡片连起来的外层底卡。
- HUD 侧：全窗口原生 Screen 薄桥接共享编辑器，拖动、等比角点缩放、九点吸附、键盘微调；相同几何用于绘制和命中；保存才写配置，Esc/取消丢弃；预览使用现有横幅画笔，不接触实时通知队列。
- 原 HUD 宽度未读取真实面板宽度限制，改为统一 ScreenMetrics；HUD 无回复控件，文字可用宽度差异保留为交互差异。
- 反馈音效新默认 100%，保留已存选择；本轮交付版本为 0.4.0-preview。
- 面板背景模糊每帧刷新。
- 横幅保持原有不透明浮动通知材质与下落动画，只修复跳转图标的强调色对比；步进箭头 hover 走全局过渡。
- 用户追加批准目录整理：个人素材同级并预创建，缓存 cache/，备份 backups/migration/，托管媒体另入 server/；兼容原 config、atomchat-data、刚部署的扁平 atomchat，校验与冲突保护保留。
- 定向模型/动作/真实 Skija 栅格回归后跑三端测试构建与九包检查，旧包备份并部署既有三端实例，记录安装哈希与未覆盖实机范围。
