# 0.3.0 设置整理与聊天输入实施方案

> 执行方式：用户指定的 Codex 原生 DeepSeek 单写执行者完整实施，负责人集中验收，再由独立强模型审查。沿用本轮多模型团队流程。

**目标：** 精简重写自定义主题预设、增加发送后关闭与会话草稿开关、补全容器圆角，并整理所有设置页。

**架构：** 保留 shared / official / Yarn 和三加载器结构，复用现有配置、绘制 token、导航、关闭动画、折叠组与整卡渲染。草稿仅在连接会话内跨聊天框保留，预设使用外观白名单和独立壁纸副本。

**技术：** Java 17/21、Skija 0.116.8、JUnit 5、现有 Gradle 工程。

## 全局约束

- 起点 main@f7b5377，前人33文件已单独提交。版本保持0.3.0。
- 不推送、不发版、不部署、不启动游戏，不增加依赖，不改绘制后端/网络协议/整体字体配色。

- 保留前轮窄窗口适配、细外框、配置原子保存及壁纸通用修复。

## 用户已确认的设计

1. 聊天/消息/输入与发送：发送后关闭聊天框默认false；保留未发送文本默认true。
2. 所有实际发送（公聊、私聊、命令；回车/按钮）成功交给客户端后，按开关走现有requestClose动画。空白/被拦截/仅插入表情图片不关；发送完仍清空输入。
3. 草稿在当前进服会话跨聊天框保留，公聊与每个私聊分别存储；退服清除，不跨重启落盘。开关关闭停止跨框保留，已有框内导航草稿不受影响；非空初始输入（如命令键的/）优先于保存草稿。
4. 预设行：现有内置主题、自定义预设、末尾＋。＋直接保存，显示预设1/预设2等；点击应用；悬停右上角×直接删除，沿用表情包的交互。不要名称输入、重命名、覆盖入口。
5. 自定义预设保存外观分类的全部可配置内容：十二种配色、透明度、宽度、UI/内容缩放、卡片浓度、圆角、模糊/外框/动画、切页方式，以及独立壁纸副本。不保存聊天/隐私/音效/身份/历史。应用无壁纸预设要清除当前壁纸；删除预设不改变当前已应用外观。
6. 圆角控制面板、按钮、输入框、卡片、弹窗等界面容器；气泡、头像、开关圆点、表情图案保留既有形状。真实绘制、裁剪、边框、阴影和hover/press层必须使用一致的动态圆角。
7. 整理所有现有设置tab。组默认展开，沿用现有折叠动画。相关开关/滑条/操作行合成整卡与细分割线；不是给每项再套新卡。

## 设置分组与整卡

| 位置 | 折叠组与内容 |
| --- | --- |
| 外观/主题 | 主题预设；圆角；消息配色（自己/他人气泡及文字、次要胶囊）；界面配色（强调色、面板、主次文字、卡片、外框） |
| 外观/显示 | 显示效果（模糊、外框）；动效（动画、切页方式）；壁纸（选择/清除） |
| 外观/调节 | 布局缩放（宽度、UI/内容缩放）；透明层次（面板透明度、卡片浓度） |
| 聊天/消息 | 输入与发送（两个新开关）；消息显示（头像样式、图片、刷屏合并、紧凑消息、时间）；互动与动效（入场动画、戳一戳） |
| 聊天/历史 | 历史存储（开关、保留天数）；历史清理（清除操作） |
| 聊天/通知 | 横幅提示；通知音效（原有通知/提及/私聊开关、音量、试听）；操作反馈（总开关、按钮/发送/面板音效、音量） |
| 聊天/高级 | 快捷操作（传送模式）；趣味特效 |
| 隐私 | 消息屏蔽显示；屏蔽名单。只整理现有可见项，不额外暴露隐藏配置 |
| 关于 | 保留作者磁贴、模组信息和第三方整卡；维护/诊断合理分组，保留清缓存二次确认 |
