# 设置分类与聊天 HUD

## 设置分类

- 外观和交互依次提供「预设」「材质」「布局」「交互」「配色」。主题、气泡和壁纸预设同页，壁纸组选图入口紧跟预设。材质按面板背景、卡片、边框与圆角分组。布局入口放在顶部，HUD 图标开关默认开启。交互按动画、操作反馈、快捷操作分组。配色按消息与界面分组，单行显示当前色块，复用取色器。
- 聊天与通知保留消息、聊天记录、通知和特效。消息页顶部放总开关，正文按输入与发送、消息显示、内容处理归组。通知按提及与引用、私聊、通知声音归组。趣味特效和新年烟花在特效页。隐私补服务器同步，关于的维护项归到「诊断与维护」。
- 两套平台映射的设置页同步，三个语言目录同步。复用折叠标题和图标，默认展开。重新分配恢复默认范围并同步教程引导。保留存档键、个人资源、已安装实例和自定义预设的现有保存行为。
- 扩大烟花和发射数量，文案按界面语言显示对应触发词。保持现有触发与播放开关的语义。

## 聊天 HUD

- 独立工作区负责原版聊天 HUD 的气泡、头像和富文本。复用面板颜色、气泡形状、身份解析与头像。玩家消息统一居左，省去引用胶囊。系统消息居左、单行省略。现有编辑器随布局页调整入口。
- 设置工作先用行为测试覆盖入口、当前页重置、配色命中和 HUD 图标默认值。源代码合并前审查两组差异，再跑三端相关和全量测试构建、语言一致性和制品检查。用隔离 Fabric 游戏核对窄面板、取色、烟花触发和 HUD 的表现。
