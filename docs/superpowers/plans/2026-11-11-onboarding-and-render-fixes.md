# v0.7.0 教程与渲染反馈实施方案

**Goal:** 修复第二轮实机反馈，按已确认交互新增可重播教程，完成三端验证后备份部署。

**Architecture:** 保留 Skija / AtomLib / 当前导航栈。教程状态、步骤、布局绘制与屏幕接线分开；本地提示记录使用 `atomchat/client/onboarding.json`。唯一 DeepSeek Flash 子代理负责设计契约与独立代码审查；Codex 负责工程实现。

**Tech Stack:** Forge 1.20.1 / Java 17；Fabric、NeoForge 1.21.1 / Java 21；现有固定 AtomLib Maven 输入。

## 已确认边界

- 新老用户均首次提醒，只有“不再提醒”“观看”；点击立即写本地持久状态，配置分发不携带，缓存清理不删除。
- 教程讲解结合实际操作，显示进度，上一步/下一步/跳过/退出；非目标区域拦截。影响性操作只演示，空态提供临时样例，退出不留存。
- 外观步骤可自由搭配或跳过，主动修改正常保存。关于页独立图标行重播，从第1步开始，不续看。
- 默认颜色、不透明度、卡片混合采用 CCB 快照 `.work/v0.7.0-onboarding/approved-palette.json`；新配置圆角25，描边3；旧配置不覆盖。
- 页面切换保留弹性，同聊天页尺寸变化不得叠加导航弹簧。点阵、右键菜单等既有设计保留。
- 第三方方案比较后再决定，不在本轮引入框架。性能问题证实后在同范围直接修，画质/设计取舍先报告。
- 验证通过自动备份部署既定三实例；不启动游戏，不提交、推送、打标签或公开发布。
