# AtomChat 0.8.0 实施计划

目标：重复消息反应独立，浮层软阴影与长文完整可见，宽面板布局有界，半透明主题可读，HUD 显示气泡图标和实际按键。

保持现有 Skija/AtomLib 绘制、共享层和映射孪生结构，不改已验收的教程、面板开合、点阵或模糊管线。保留用户已有调研文档。

- [x] 反应：先补重复消息回归；使用消息身份，覆盖合并副本、多人同步和无签名消息。用户已确认客户端与服务端一起更新，v2 可选频道使旧端保持原回显。
- [x] 浮层：沿绘制调用链核对缓存、透明层、祖先裁剪；补原生像素检查；Toast 按可用宽高换行并限制绘制区域。
- [x] 宽屏：UiLayout 居中约束上栏、底栏、内容列；设置首页保留 2×2 正方形、设置最大边长；绘制与点击共用几何。
- [x] 主题：逐对核对文本/表面颜色，半透明预设沿用默认卡片材质；不覆盖用户已保存的自定义主题。
- [x] HUD：白色实心气泡和三点镂空、字体和实际绑定键随原版 GUI 缩放；F1/其他界面隐藏，面板开合时用同一进度对称平移淡出/淡入，关闭动画时直接切换。
- [x] 验证：行为回归、原生离屏图、三端串行 test/build、targets/JAR/bare/diff；整批集中独审，修正后只复核受影响范围。追加修复设置 tab 标题栏跟随动画：标题栏固定、内容变换，点击坐标同源。仅部署已授权三实例，不启动游戏、不提交推送发布。

实机交互、GUI 缩放、整合包渲染和用户观感仍由测试实例确认，离屏结果不代替实机验收。
