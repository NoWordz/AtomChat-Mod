# 面板与浮层修订实施计划

**目标：** 恢复边框规格，修正浮层、教程和提示，并评估 GPU 热点；真实面板支持手柄编辑。

**架构：** 保留现有真实面板与输入分发，编辑状态只在手柄命中时截获输入，几何以矩形和现有配置为准；复用 HUD 编辑器的辅助线与控件样式。提示文字复用现有字体换行，浮层沿用现有阴影原语。

**约束：** 三平台；默认边框 #14161B、4px、最大 6px；不恢复已删 HUD 图标或调整动画；实施代理不启动游戏、部署或提交；主代理复审后按既有授权备份部署。

1. 确认基线与截图，检索 build、.work、docs 和近期日志；记录未能确定的 DeepSeek 日志。
2. 先为边框默认值、上限和预设存取增加断言并运行红灯；同步配置、两个映射设置目录及三平台中英文描述，重新运行测试。
3. 为长提示添加多行布局与堆叠边界测试；按可用文字宽度换行，按行数计算高度与堆叠位置，验证实际离屏绘制。
4. 检查真实教程步骤、关于页和浮层绘制，分别修正文案及缺失的软阴影，检查裁剪边界并留离屏图。
5. 梳理真实面板几何、持久化和输入路径；在现有坐标系叠加角点及移动手柄，独立内容缩放滑条，提供保存、取消、视口边界和退出清理；先测试几何和事件再接线，保持其他区域交互。
6. 复查现有 GPU 测量与当前热点，只有证据支持时修改；记录测量范围，不将离屏结果当成游戏整帧。
7. 运行针对性行为和渲染测试、三平台构建及仓库守卫，日志先落盘；报告基线、失败、未验证项和交由主代理复审的风险。

## 面板编辑器接线方案

- 用独立 `PanelEditorModel` 保存编辑开始时的配置快照，编辑时仅更新矩形尺寸、归一化位置和内容比例；取消恢复快照，保存才写磁盘。
- `ScreenMetrics` 在自定义位置启用时，根据可用视口计算并夹紧位置；旧配置未启用时沿用原始定位。绘制和鼠标都使用现有虚拟坐标转换。
- 在真实 `AtomChatScreen` 绘制结束后叠加辅助线、四角缩放手柄、移动手柄及 HUD 风格底栏；手柄及底栏命中优先消费鼠标，其他区域继续走原事件门；退出时自动取消未保存更改。
- 测试移动、四角缩放、边界、窗口变化、缩放独立、取消和坐标变换；对三端孪生接线及离屏图执行验证。
