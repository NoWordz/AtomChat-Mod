# 面板外关闭与半屏模式实施方案

**目标：** 左键点击面板外世界画面关闭界面；新增左、上、下贴边的半屏模式，现有宽度滑条按模式分别记忆。

**结构：** 沿用现有 Skija 渲染、ScreenMetrics 坐标入口、UiLayout 纯布局与 InputGate 事件链。配置与设置为独立实施单元；主流程处理几何、背景/模糊/弹层轮廓与点击。保留手机模式与现有导航和主题，不引入新渲染框架或网络协议。

**参考：** 用户图片已保存 `.work/half-screen-reference/reference.png`。参考图聊天区域左上起点为屏幕边缘，底部输入栏贴底，右侧保留世界画面；颜色、频道与图标不是本轮替换目标。Tuui 本地反编译的 `SkijaScreen`/`GuiScaleAdapter` 继续作为单一绘制与输入坐标转换的参考，不搬入 Kotlin 或其他业务。

- [x] 在 `AtomChatConfig` 增加 `halfScreenMode`、独立 `halfScreenWidth`（默认 600），`activePanelWidth()` 与 `setActivePanelWidth(float)`；手机继续保存 `panelWidth`。
- [x] official/Fabric 两份 `SettingsCatalog` 的现有 width 滑条改为当前模式宽度；外观→调整→布局增加半屏开关，中英文三端同步。
- [x] 先验证缺失功能导致测试失败，再验证滑条切换、配置重载、旧配置默认、主题应用不覆盖布局偏好。

## 几何与输入

- [x] `ScreenMetrics` 两份按模式得到同一个面板：半屏 x/y=0、高=视口虚拟高度，宽度仍走既有尺寸与缩放规则并限制在视口内；手机原公式不变。
- [x] `UiLayout` 半屏顶栏与底栏直接贴边，内容列保留已有阅读内距；三端绘制与命中继续读取同一布局。
- [x] 统一 `PanelBackground` 内部轮廓：半屏无手机边框内缩或圆角，背景、壁纸、模糊和三弹层都覆盖到屏幕边缘；半屏关闭环形 bezel。
- [x] 新增共享面板外点击处理器，置于关闭状态之后、弹层之前，仅左键面板外点击触发正常关闭并消费事件；拖动/松手不触发关闭，面板动画门仍生效。
- [x] 实测几何、画布边缘像素及事件消费；多窗口/GUI 缩放/内容缩放覆盖旧模式与新模式，先红后绿。
