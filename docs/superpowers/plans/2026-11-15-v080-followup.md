# 0.8.0 实机反馈与性能排查

目标：精确撤销公共限宽，缩小 HUD，改善面板开合，并依据 CCB 实测定位 AC / AtomLib 的渲染成本。

## 已确认范围

- 公共栏位、列表与内容列恢复随面板伸展；保留设置四张方卡的大小上限与居中。
- HUD 图标、字号、间距全 GUI 档位缩小约 20%；白色填充、三个透明孔、软影与原版缩放保留。
- 只优化面板开合与 HUD；不调整切页手感，设置 tab 标题栏仍固定。
- 开屏约 240 ms、关屏约 180 ms，柔和、无回弹。关闭触发事件被消费，后续键盘、鼠标与快捷栏立即恢复，退场画面不交互。
- 默认改为 SLIDE，仅影响新配置与恢复默认，保留已有选择。
- 性能优化不减少模糊、阴影、点阵、动态图等观感。CCB 为主验收实例，三端构建与回归。
- 继续保留未提交的 0.8.0 其他修复及用户原有调研文档；不启动游戏、提交、推送或发布。

## 实施顺序与验收

- [x] 复用现有 CCB 0.8.0 / AtomLib 0.4.0 日志，审计 HUD、面板稳态、开屏、过渡的完整调用链；区分 CPU 提交、GPU 工作与等待，不将旧离屏数字当实机收益。
- [x] `UiLayout` / 两映射消费者仅撤销公共限宽；`LayoutTokens` / `ChatShortcutHint` 缩小 HUD；配置默认值改 SLIDE。复用布局与原生像素测试。
- [x] 面板开合使用有界无回弹进度，HUD 共用可打断时间线；三端 Screen 立即释放输入，HUD 绘制拥有有界退场资源，换世界、换屏与快速重开正确清理。补行为回归与连续帧检查。
- [x] 只对已定位的成本实施无损优化；如涉及 AtomLib，先核对实际编译 / 安装版本与源码，避免将 AC 调用量问题归给桥内部。
- [x] 集中独审一次；修正后限定复核，运行受影响测试与三端构建；记录实际收益、失败、跳过与实机限制。
- [x] 按持续授权仅部署已验证候选到三个测试实例，备份与独立回读；若游戏在运行则保留成品等待退出。

## 初始证据与待核对项

- 用户截图：`docs/evidence/2026-11-15-v080-followup/user-hud-scale-5.png`。5× 下约 80 px 图标 / 50 px 字号，占左下角明显偏大；世界开启光影，截图显示 113 FPS。单张图不证明 UI 的增量耗时。
- CCB 日志快照：`build/v080-followup/ccb-user-session.log`，版本 AC 0.8.0 / AtomLib 0.4.0。末段设置 repeat steady p50/p95=2.05/4.03 ms，transition=5.52/15.11 ms；不是同场景 A/B，不能据此宣布根因或收益。
