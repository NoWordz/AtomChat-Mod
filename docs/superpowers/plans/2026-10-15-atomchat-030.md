# AtomChat 0.3.0 Implementation Plan

> **Implementation mode:** 6.1-sol performs read-only repository reconnaissance and drafts code; the primary agent reviews and applies the patch.

**Goal:** Promote AtomChat to 0.3.0 with a local avatar-style option, a collapsible private-chat list, and compact author tiles on the About page.

**Architecture:** Keep the current Skija UI and config architecture. Store avatar style in the client config, make skin face and hat layers available from the existing skin sampling path, and update the official-mapping and Fabric source mirrors together. Keep collapse state in the screen-owned conversation page, and add author imagery as bundled resources.

**Tech Stack:** Java, Gradle, Minecraft Forge 1.20.1, Fabric 1.21.1, NeoForge 1.21.1, Skija.

## Global Constraints

- Root `mod_version` changes from `0.3.0-Preview` to exactly `0.3.0`.
- Avatar style is client-only, stored locally, defaults to AtomChat, and is selectable under Settings > Chat > Messages.
- E33Chat style uses the square skin face with an expanded hat layer and bypasses custom-avatar display without deleting saved custom-avatar data.
- Avatar editing and clearing controls on Profile are disabled while saved custom-avatar data remains intact.
- Private-list folding starts expanded and retains its state only while the same chat screen remains open, matching Settings fold lifetime.
- About shows E33EPUS and NoWordz in two small side-by-side static tiles using the supplied pixel images.
- Do not push, tag, or publish. Preserve all pre-existing uncommitted Linux packaging and font work.
- Do not add or run tests unless the user asks; use only non-test checks and compile-only tasks if validation is performed.
