# AtomChat 1.0.0-Preview 实施计划

从三端已验收的 0.9.8 出发。先复现 516 的分享问题，采集同场景性能基线，同时盘点前后端生产路径。最终交付三端本地候选包、备份部署和可核对的验收记录。

## 版本、分工和完成条件

- 起点为 `codex/atomchat-v0.9.8` 的 `93ecb510`，对应已交付代码 `15645ecb`、AtomLib 0.7.1。目标为 Forge 1.20.1、Fabric 1.21.1、NeoForge 1.21.1，覆盖 Official 和 Yarn 映射层。
- 每个任务最多派两位子代理。每人使用独立工作区和互不重叠的写入范围。主代理负责综合证据、集成、规模与风险判断、与用户的主题循环及三端交付。子代理可按需承担 AtomChat 后端或独立复审。确认 AtomLib 是实测热点后，把 AtomLib 定向修复交给一位子代理。互审的人检查自己未实现的部分。主代理串行运行共用测试机上的可比性能样本。
- 三端都保留 0.9.8 的画面与原有动效，包括各画质档、布局、文字与截断、抗锯齿、阴影、点阵、模糊、教程与 HUD；主题变化以用户逐个确认的改动为准。
- 全量审计记录范围、生产入口、证据、结论和验证缺口。优先修实证问题。对可复现的明显掉帧和卡顿给出改善证据，各主场景复查回退。大范围架构变更与新插件专门适配由具体复现和方案触发用户决策。
- 验收范围包括 516 原场景、NCR 开关、Paper 和 Youer 上现有插件桥接、三端图形与性能、用户定稿主题和备份部署。公开预发行另行决定。
