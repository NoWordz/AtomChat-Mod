# 0.3.2 图片预览与交互修正

沿用 shared + official/Fabric 映射副本，不迁移渲染架构。基线 main@2e6c3ac，开工工作区干净。

- [x] 图片预览：`shared/.../image/ImagePreviewOverlay.java`。淡入同时作用于图片，位置/透明度使用现有指数收敛；滚轮以指针为锚，适配尺寸为最小倍率，最大 8 倍；放大后左键拖动，缩回自动居中。图片区域与关闭按钮分开裁切，按下/拖动/释放/滚轮接入三个平台的 `ModalInput`。新增真实图像像素与手势测试，先失败后修正。
- [x] 弹层角部：`PanelBackground` 提供与实际外框一致的内缘裁切，图片预览、`ColorPickerOverlay`、`ImageCropper` 都在各自 save/restore 内使用。真实 Skija 光栅检查三种弹层、默认/方角、大圆角、四个角与边框留白，不只检查遮罩自身。
- [x] 主题：两份 `SettingsSectionPage` 的默认主题卡与其他内置卡采用一致的保存预设互斥条件。实际主题条像素检查：保存/应用后默认卡无边，保存卡有边。
- [x] 过滤：`WorldFeedFilter` 把选择写入 `AtomChatConfig`，新屏幕和 reload 后都读取配置；旧配置默认 ALL，空值安全回退。覆盖真实 feed 与 header 图标，确保不改消息/未读。
- [x] 验证与交付：三端测试和 Windows 构建、seams/targets/孪生/差异检查、独立审查；更新版本、双语日志、STATUS 和验证记录。游戏实机动效、滚轮触感、GPU 仍需用户验收；本轮不自动提交或部署。
