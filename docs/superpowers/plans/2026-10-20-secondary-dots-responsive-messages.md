# 次要区域点阵与窄面板消息布局

用户授权“做点阵和布局”，创作者接口与更多气泡暂缓。本轮沿用现有 Skija、DotTexture、手机风面板与已验收字号，不换框架、不增加配置项。

## 设计与顺序

1. 空会话/空列表：复用现有图标与文案，在其背后加一块有边界的主题色放射点阵；不会占用正常消息或列表项。
2. 个人资料：仅默认渐变头图区加淡点阵，照片与皮肤图保持原状，头像、文字和编辑按钮画在装饰上方。
3. 表情/快捷短语浮层：在浮层底边到输入栏之间，对准触发按钮保留一小段渐隐点阵；随浮层现有透明度/缩放出现，不增加额外动画，裁切不进入输入栏。
4. 消息布局：新增共享的消息几何规则，由头像占位、间隙、对侧自适应留白和宽面板行宽上限派生最大气泡宽度；正文、图片、引用与反应条的绘制/测量/命中读取同一规则。保留字号、头像尺寸、气泡内边距和纵向间距。
5. 先用真实消息绘制和像素回归复现旧版窄宽不足/装饰缺失，再实施并检查深浅主题、窄宽与常规宽度。两个映射副本同步；布局与图片尺寸变化安排独立审查。
6. 三端完整测试和构建、静态闸门、Windows/Linux 六包核验；生成实际生产绘制预览；继续备份部署用户指定的 CCB Fabric 实例。未获新增提交或推送授权。

本轮是对前轮已提交实现的续改，保留未提交的浅色配色调整。CPU 预览不代替游戏内视觉验收；不启动客户端。
