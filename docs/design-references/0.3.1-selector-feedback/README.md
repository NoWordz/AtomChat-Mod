# 气泡选择器与强调色反馈

用户于 2026-10-20 在 CCB 实例实测后提供两张截图。

- 气泡选择器风格反馈.png：界面圆角设为零。主题预设位于带标题的整卡中，缩略图有阴影，名称在缩略图下方，内容可横向滚动；气泡选择器却是三块等分描边卡，名称位于卡内，视觉语言不同，且排列在圆角组之后。
- 导航选中颜色与圆角反馈.png：导航选中底色呈偏灰蓝色，内层底色圆角比外栏小，未形成平行内缩的轮廓。

本轮要求：气泡选择器直接复用主题预设卡片绘制与滚轮/拖动机制，保留三种形状，顺序为主题预设、气泡样式、圆角；选中底色直接使用强调色，悬停不再按明暗底色派生 RGB；导航选中与悬停轮廓随外栏圆角内缩。继续沿用已授权的 CCB 部署目标。
